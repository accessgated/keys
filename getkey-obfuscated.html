Hãy khai triển biểu thức rồi nhập hai hệ số được yêu cầu. Bạn có thể xem hướng dẫn dưới đây trước khi làm.

Cách giải từng bước

Với dạng (x + a)(x + b), nhân từng hạng tử trong ngoặc thứ nhất với từng hạng tử trong ngoặc thứ hai:

  1. Nhân x * x = x².
  2. Nhân chéo: x * b = bx và a * x = ax.
  3. Nhân hai số còn lại: a * b = ab.
  4. Gộp hai hạng tử chứa x: bx + ax = (a + b)x.

Vậy công thức chung là (x + a)(x + b) = x² + (a + b)x + ab.

Ví dụ: (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6.

Đề yêu cầu nhập hệ số của x trước, rồi đến hệ số tự do. Ví dụ trên nhập 5, 6.

Nếu có số âm, vẫn áp dụng phép cộng và nhân số nguyên bình thường. Nếu thấy + 0, số đó bằng 0 nên hạng tử tương ứng không làm thay đổi kết quả.
